# Security Policy

## Project scope

SupplyShield AI is an educational and hackathon prototype. It is not a complete software composition analysis platform and does not guarantee that an application or dependency is secure.

## Reporting a vulnerability

Please do not publish exploitable details or sensitive information in a public issue. Use GitHub's private vulnerability reporting feature for this repository if it is enabled. If private reporting is unavailable, contact the repository maintainer privately through their GitHub profile and include:

- A concise description and potential impact.
- Steps to reproduce, using a harmless proof of concept where possible.
- The affected file, commit, or version.
- Any suggested mitigation.

Please allow reasonable time to investigate before publicly disclosing an unpatched issue.

## Safe use

Do not upload secrets, credentials, private package-index URLs, or sensitive manifests to the hosted demo. Dependency names and versions are sent to the public services documented in the README.
